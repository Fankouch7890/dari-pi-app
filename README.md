# 🏛️ Dari Pi (داري باي)

منصة العقارات والتوكنة العقارية الأولى في تونس المعتمدة على شبكة **Pi Network** و **DP Token**.

---

## 📌 عن المشروع
منصة **Dari Pi** تمكّن المستخدمين ورواد شبكة Pi من شراء، بيع، واستثمار العقارات في تونس بطريقة آمنة عبر العقود الذكية، مع توفير خاصية التوكنة (تقسيم العقار إلى حصص استثمارية) والتعدين اليومي.

---

## ✨ أهم المميزات
* 🪙 **الدفع بـ Pi:** تسجيل الدخول والمعاملات عبر Pi SDK.
* 🏬 **التوكنة العقارية:** شراء حصص في العقارات بـ DP Token.
* 🗺️ **البحث والخريطة:** تصفح العقارات حسب الولايات التونسية.
* ⛏️ **التعدين اليومي:** كسب مكافآت يومية من رمز DP.
* 🇹🇳 **دعم كامل للهاتف:** واجهة سريعة ومتجاوبة باللغة العربية والإنجليزية والفرنسية.

---

## 🚀 التشغيل
افتح ملف `index.html` في أي متصفح، أو استخدم **Pi Browser** للحصول على تجربة الربط الكاملة.
